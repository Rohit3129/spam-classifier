# Secure Data Storage Smart Contract

This is a secure data storage smart contract built with Solidity that allows users to:
- Store data securely on the blockchain
- Control access to their data
- Grant and revoke access to other users
- Retrieve data safely

## Security Features

- Access control mechanisms
- Data ownership tracking
- Event logging for all important actions
- Immutable contract owner
- Protected data structures
- Input validation

## Setup

1. Install dependencies:
```bash
npm install
```

2. Compile the contract:
```bash
npx truffle compile
```

3. Deploy to your chosen network:
```bash
npx truffle migrate
```

## Usage

The contract provides the following main functions:

- `storeData(bytes32 _id, bytes32 _data)`: Store new data with a unique ID
- `getData(bytes32 _id)`: Retrieve data if authorized
- `grantAccess(bytes32 _id, address _user)`: Grant access to another user
- `revokeAccess(bytes32 _id, address _user)`: Revoke access from a user
- `hasDataAccess(bytes32 _id, address _user)`: Check if a user has access to data

## Security Considerations

- All data is stored encrypted as bytes32
- Only authorized users can access data
- All access changes are logged via events
- Owner-only functions are protected
- Data ownership is strictly enforced
